## 💼 Projetos em Destaque

### 🖼️ Descubra Recife
Aplicativo mobile para divulgar eventos, pontos turísticos, igrejas e muito mais. Trazendo visibilidade e recursos financeiros para a cidade do Recife, mostrando o quanto podemos explorar lugares incríveis.

### 🐕 Pet Id
Protótipo desenvolvido para projeto da faculdade, visando solucionar problemas para tutores de PET, com diversas funcionalidades, incluindo serviços com veterinários, localização de locais Pet Friendly e etc.

### 🖼️ Descubra PE
Um site desenvolvido para divulgar locais de Pernambuco, com mapas interativos e gamificação, podendo montar a sua própria trilha de locais.
